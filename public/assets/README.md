# Design system assets

[tedx-amsterdam-design-system/assets](https://github.com/tedx-amsterdam/tedx-amsterdam-design-system/tree/main/assets).

`/assets/`, but the npm package does not ship them yet.

Remove this folder once the design system publishes its assets and the
website loads them from the package instead.
